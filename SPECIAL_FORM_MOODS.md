# SPECIAL FORM MOODS — Pokezom design system (user-approved direction, Nov 15, 2026)
Every special form category gets its own environment, particle behavior, and typography.
Set via config `mood` in the long-form template (template/index.html). Registered moods:

- (none) Standard: type-driven world (primary type = sky/world, secondary = accents), 3-layer flow particles in type colors, clean white title.
- shadow: abyssal violet-black sky, purple smog banks, violet/crimson embers, steel-violet name gradient, glowing crimson sub. (Ep.1 s5)
- future (Future Paradox): cyber-indigo/teal void #071324→#140a2e, holographic hex grid, neon cyan + electric-yellow aurora, rising data-motes (cyan squares/hexagons) + fast yellow voltage sparks, chrome→neon-cyan name (#fff→#00f0ff) with cyan glow, glowing yellow sub. (Ep.1 s6 Iron Thorns)
- past (Past Paradox): primal volcanic amber/crimson sky, ash drift + warm motes, molten-gold→scarlet name, amber sub.
- mega (single Mega): magenta/violet/gold euphoria sky, gold starburst + hollow gold/magenta rings, radial surge, gold→crimson name, radiant gold sub. (Ep.1 s7)
- mega-x: cobalt/indigo/cyan euphoria sky, blue starburst + cobalt/cyan rings + blue surge, platinum→cobalt name with blue glow, icy cyan sub.
- mega-y: solar crimson/orange/gold euphoria sky, solar starburst + gold/scarlet rings + orange surge, solar-gold→scarlet name, solar-orange sub.
- gmax (Gigantamax/Primal): crimson-magenta storm sky, heavy vignette, crimson/pink motes, crimson→white-core name with red glow, pink sub. (v1: palette/type layer; storm-cloud layer TBD when first used)
- mecha (PokéStar robots): steel→hazard-gold name gradient (typography only; pairs with studio stills + envFX). (Ep.1 s4)

Rule: a special form NEVER sits on the standard world with plain white text. When a new form category appears, register its mood here + in the template first.
